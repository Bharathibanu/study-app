# Tables 12–30 and visual SSC maths tricks

## Multiplication tables

Open **Quick Revision / Revise → Tables**.

- Choose any table from **12 through 30**.
- Choose multipliers **×1 through ×20**, or extend to **×50**.
- Choose **Mixed: all tables 12–30** for mixed practice and an all-tables reference grid.
- Learn, Practice and Flashcards use the selected table/range consistently.
- Practice generates 15 different questions from that range.
- Changing the table/range discards the current unsaved drill and starts a matching set when in Practice mode.
- Table/range preferences are remembered on this device, not synchronized as account data.
- Completed table drills retain their table/range alongside the Quick Revision score.

The daily Tables checklist still marks the category complete after a finished table drill; it does not mean all 19 tables have been mastered.

## Visual shortcuts

Open **Maths Tricks** from the sidebar or More. The five original multiplication levels now have a step diagram, applicability conditions, and a worked model question for every one of the 16 shortcut topics. Expand a model question to see its solution and answer.

Examples include ×4, ×5, ×11 carrying, ×9/99, ×25/50/125, double-and-halve, squares ending in 5, numbers near 100, difference of squares, square expansion, two-/three-digit multiplication, digit-sum checks, exact percentage fractions and order of operations.

The live near-100 demo accepts whole numbers from 80 to 99 and handles a carry when the product of the gaps is at least 100. Digit-sum checks are explicitly only a partial error check: matching remainders cannot prove an answer is right.

## Additional SSC maths methods

Thirteen method cards include diagrams, applicability limits, a worked example, an interactive model question and topic-practice links:

1. Successive percentage changes.
2. Profit, loss and discounts, using the correct percentage base.
3. Time & work using LCM work units and efficiency.
4. Relative speed and km/h ↔ m/s conversion.
5. Average speed for equal distances.
6. Ratios using equal unit parts.
7. Alligation for a two-component mixture.
8. Average changes using totals.
9. Simple versus compound interest over two annually compounded years.
10. Algebraic identities.
11. Right triangles and Pythagorean triples.
12. Area and volume scaling for similar shapes.
13. Standard-angle trigonometry.

These are **original model questions, not official SSC PYQs**. A shortcut should be used only when its stated assumptions hold. For example, equal-distance average speed differs from equal-time average speed, and 16.67% is only approximately 1/6; the exact value is 16⅔%.

## Interactive question and progress

Use **Try a model question**, enter the answer and press **Check answer**, then **See score** to record the completed attempt. Explanations use the actual numbers in the interactive question. A wrong completed attempt is also added to the SSC Mistake Notebook. These attempts affect topic accuracy/speed, not timetable study minutes.

Use **Mark as mastered** for a method you understand; this is a personal flag, not proof of mastery. Additional SSC-method flags are independent of the five original multiplication-level progress bar.

Diagrams use scalable SVG with descriptive labels and inherit the app’s light/dark colours. Worked answers stay behind expandable model-question controls. The app retains reduced-motion support and caches the maths module for offline use.
